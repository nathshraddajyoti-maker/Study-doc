Free Android installation

Study Dock is currently a web app file. To install it like an app without paying for APK export, the practical route is to host the PWA files on a free HTTPS static host (for example, GitHub Pages), then open the URL in Android Chrome and choose Install app or Add to Home screen. The browser must be able to access the hosted files; simply opening a local HTML file does not install a PWA.

This bundle includes a web manifest and offline cache file for hosting. It is not an APK, and it has not yet been published online.
